po0-clash v5.2.0：全新磨砂玻璃界面，重做操作结构与应用图标。

## 本次更新

- 全新磨砂玻璃设计：半透明玻璃面板、高光描边与随页面流动的极光背景，浅色 / 深色 / 纯黑三种模式均适配
- 重做操作结构：宽屏左侧为常驻控制栏（连接光球、出站模式、各空间实时状态、网速与出口 IP），右侧为工作区；窄屏为玻璃侧栏；手机为悬浮玻璃底栏
- 仪表盘改为固定布局的控制中心：点击光球即可开关代理，同屏显示当前节点、po0 状态、当前配置、网速、网络检测与内存
- 连接、请求、日志合并为「活动」页，顶部分段切换
- 设置改为分组的玻璃磁贴：外观、网络与内核、应用、其他
- po0 页面重做：状态主面板、自动加白与刷新间隔、令牌列表、白名单结果
- 全新应用图标与托盘图标（Android、Windows、macOS）
- 默认主题色改为鸢尾蓝，弹窗背后自动虚化

## 升级说明

- 从 5.1.0 直接覆盖安装即可，设置全部保留
- 仍在使用旧默认主题色的会自动换成新的默认色；自己选过的颜色保持不变
- 仪表盘不再支持自定义组件布局，原有的布局设置不再使用

## 安装

- Windows：po0-clash-5.2.0-windows-amd64-setup.exe（安装包）或 .zip（免安装）
- macOS：curl -fsSL https://raw.githubusercontent.com/yuuuki-creation/po0-clash/main/scripts/install-macos.sh | bash
- Android：po0-clash-5.2.0-android-arm64-v8a.apk（主流机型），可与官方 FlClash 共存

## 已知限制

- Android 首次开启自动加白后需重启一次 VPN，直连路由才会生效
- Android 从最近任务划掉 po0-clash 后停止检查，重新打开应用即恢复
- 同时在用的网段超过白名单容量（5 条，服务端已有的固定记录也占名额）时，各设备会互相挤占
- 与其他代理客户端同时开启系统代理或 TUN 会互相抢占，请只在一个应用里开启
- macOS 版本未经 Apple 公证，安装脚本会移除隔离属性
