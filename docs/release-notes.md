po0-clash v5.2.1：改为苹果液态玻璃风格，虚拟网卡与系统代理二选一，修正按钮点击区域错位。

## 本次更新

- 外观改为苹果液态玻璃风格：中性背景、不透明的分组卡片，只有侧栏、底栏、分段控件、工具栏和弹窗是玻璃；默认强调色改为系统蓝，开关为系统绿
- 连接按钮改为控制中心式圆形按钮，开启时填满强调色；设置页改为 iOS 设置式分组列表
- 深色模式默认改为 macOS 深灰，「纯黑」切换为 iOS 纯黑
- 桌面端虚拟网卡与系统代理改为二选一：打开一个会自动关闭另一个，且不能两个都关；新安装默认虚拟网卡
- 虚拟网卡授权被取消或失败时自动改用系统代理并提示，再次开启会重新请求授权
- 出口 IP 移到开关右侧（Android 为 VPN 右侧），点击重新检测，长按查看说明
- 宽屏侧栏新增虚拟网卡 / 系统代理切换
- 修正分段控件、手机底栏等只有部分区域可点、看起来与实际可点击区域不一致的问题；修正窄窗口侧边导航高亮错位
- 窄窗口下开关只保留名称，选项改为长按打开
- 应用图标与托盘图标改为系统蓝液态玻璃风格；Android TV 启动器图标恢复为 80dp 规格

## 升级说明

- 从 5.2.0 直接覆盖安装即可，设置全部保留
- 仍在使用 5.2.0 默认主题色的会自动换成系统蓝；自己选过的颜色保持不变
- 以前虚拟网卡与系统代理同时开启或同时关闭的，升级后会改为只开虚拟网卡；首次开启虚拟网卡需要系统授权（macOS 输入管理员密码，Windows 安装服务）

## 安装

- Windows：po0-clash-5.2.1-windows-amd64-setup.exe（安装包）或 .zip（免安装）
- macOS：curl -fsSL https://raw.githubusercontent.com/yuuuki-creation/po0-clash/main/scripts/install-macos.sh | bash
- Android：po0-clash-5.2.1-android-arm64-v8a.apk（主流机型），可与官方 FlClash 共存

## 已知限制

- Android 首次开启自动加白后需重启一次 VPN，直连路由才会生效
- Android 从最近任务划掉 po0-clash 后停止检查，重新打开应用即恢复
- 同时在用的网段超过白名单容量（5 条，服务端已有的固定记录也占名额）时，各设备会互相挤占
- 与其他代理客户端同时开启系统代理或 TUN 会互相抢占，请只在一个应用里开启
- macOS 版本未经 Apple 公证，安装脚本会移除隔离属性；每次更新后首次开启虚拟网卡需重新输入管理员密码
