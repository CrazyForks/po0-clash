# 0010. 改为苹果液态玻璃风格

- 状态：已采纳
- 日期：2026-09-29
- 取代：[0009](0009-frosted-glass-ui.md) 中的视觉部分（操作结构不变）

## 背景

5.2.0 的磨砂玻璃用了彩色极光背景、渐变与发光，维护者认为过于花哨，要的是苹果液态玻璃（Liquid Glass）那种克制的质感。

## 决定

- 背景为中性色：浅色 `#F2F2F7`，深色为 macOS 深灰 `#1C1C1E`，开启「纯黑」时为 iOS 纯黑。不再有极光与按页面变化的场景。
- 内容用不透明的分组单元格（浅色白、深色 `#2C2C2E` / `#1C1C1E`），不加描边与阴影。
- 只有悬浮控件是玻璃：侧栏、侧边导航、手机底栏、分段控件、工具栏按钮组、弹窗与菜单。玻璃为半透明填充，
  需要时对下方内容做模糊并提高饱和度，边缘有随光线变化的高光描边，阴影只画在外侧。
- 强调色默认系统蓝（`#007AFF` / `#0A84FF`），开关用系统绿，状态色取苹果系统色（`GlassTone`）；
  图标为单色，只有设置页沿用 iOS 设置的纯色方块图标。
- 连接按钮改为控制中心式的圆形按钮，开启时填满强调色。
- 应用图标与托盘图标改为系统蓝底、透明玻璃圆盘与白色圆环。

## 影响

- 5.2.0 的默认主题色读取时迁移到系统蓝。
- 纯黑模式从「深色背景改纯黑」变为「macOS 深灰 / iOS 纯黑」二选一。
