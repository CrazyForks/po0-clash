# 0009. 磨砂玻璃界面与新的操作结构

- 状态：已采纳
- 日期：2026-09-29
- 取代：[0008](0008-material3-on-every-platform.md)

## 背景

维护者认为 5.1.0 的 Material 3 界面不够好看，要求抛掉以前的设计和整个操作结构，改为磨砂玻璃风格。

## 决定

- 三端仍然共用一套界面，组件不按平台分支外观；视觉语言改为磨砂玻璃（`docs/features/glass-ui.md`）。
- 结构性面板（侧栏、工作区、卡片）只给静态的极光背景着色，不做实时模糊；只有内容会在其下滚动的浮动层
  （手机底栏、弹窗背后）使用 `BackdropFilter`，控制 GPU 开销。
- 操作结构按窗口宽度分三档：宽屏为常驻控制栏 + 工作区，窄屏为玻璃侧栏 + 工作区，手机为悬浮底栏。
  原仪表盘改为固定布局的控制中心，不再支持编辑组件；连接、请求、日志合并为「活动」；工具页改为设置磁贴。
- 形状改为连续曲率圆角（superellipse），圆角档位放大；动效仍只取 `Durations` / `Easing`。
- 应用图标与托盘图标重新设计，源文件在 `assets_source/images/icon/`，由 `tool/generate_app_icons.sh` 生成。

## 影响

- `AppSettingProps.dashboardWidgets`、`DashboardWidget`、`SuperGrid` 等仪表盘编辑相关代码删除，旧配置中的字段被忽略。
- 5.0.0、5.1.0 的默认主题色读取时迁移到新的默认色。
