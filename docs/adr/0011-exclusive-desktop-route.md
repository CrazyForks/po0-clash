# 0011. 桌面端虚拟网卡与系统代理二选一

- 状态：已采纳
- 日期：2026-09-29

## 背景

两者同时开启会让流量被重复接管，两者都关闭时代理虽在运行却没有流量进入。FlClash 另有一个老问题：开启虚拟网卡
需要系统授权（macOS 管理员密码、Windows 安装 helper 服务），授权被取消或失败后开关仍显示开启，内核却没有 TUN。

## 决定

- 桌面端任何时刻恰好开启其中一个：打开一个会关闭另一个，关闭唯一开启的那个会打开另一个。
  规则是纯函数 `reconcileDesktopRoute`（`lib/common/desktop_route.dart`），`AppStateManager` 监听两个设置并调用
  `SystemAction.reconcileRoute`，因此首页、侧栏、设置页、托盘与快捷键的任何入口都受约束。
- 新安装默认虚拟网卡；读取到两者都开或都关的配置时，以虚拟网卡为准。
- 授权失败或被取消时自动改用系统代理并提示；授权状态重置，下次再开虚拟网卡会重新请求授权。
- Android 使用 VPN，不受此规则影响。
